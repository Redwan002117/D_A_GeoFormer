About this dataset

Real, publicly-labeled SpaceNet-8 tiles pulled directly from the public spacenet-dataset S3 bucket — no AWS credentials needed. Covers two real flood events (a 2021 Germany flood, and Hurricane Ida's effects in Louisiana). A third region (Louisiana-West) exists in the same bucket but ships imagery only — SpaceNet never released public labels for it; it's their own blind competition test set.
